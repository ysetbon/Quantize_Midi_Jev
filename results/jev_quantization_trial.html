Round 2: Jev names every note

Here Jev got the bar's notes instead of ready-made options: pitches, when each note starts, the gap to the next note in ms and how long each key was held. It answered one question per note: which written value is it, from a whole note down to a 32nd, including triplets, sextuplets and grace notes. "Fit to bar" keeps Jev's answers but makes the values add up to exactly one bar. The time signature was given, and all of a bar's answers came back in one request.
